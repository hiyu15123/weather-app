# 天気予報アプリ
お天気アプリ

## デモ
【公開URL】

## 機能
- 都市を選んで、24時間先までの1時間ごとの天気を表示
- 現在地の天気を表示（位置情報を使用）
- 読み込み中・エラー時のメッセージ表示

## 使用技術
- HTML / SCSS / JavaScript（フレームワークなし）
- Open-Meteo API

## 工夫した点
- 位置情報の取得をPromiseで扱えるようにしました。ブラウザの位置情報取得はコールバック形式のため、`new Promise`で包んで`await`で使える形にし、許可されなかった場合はメッセージを表示しています。
- 役割ごとにファイルを分けました。どこで問題が起きたか追いやすく、変更も1か所で済むためです。
- アクセシビリティに配慮しました。表の見出しに`scope`を付けて見出しとデータを結びつけ、表示の変化は`aria-live`で読み上げソフトにも伝わるようにしています。キーボードだけで操作できます。Lighthouseのアクセシビリティスコアは100です。
